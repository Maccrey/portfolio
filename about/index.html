개발자 소개

문제를 발견하고 끝까지 제품으로 만드는 개발자

50세에 개발을 시작한 뒤 아이디어를 실제 사용 가능한 서비스로 연결해왔습니다. 기획부터 구현, 출시, 운영 중의 개선까지 직접 경험하며 배운 점을 기록합니다.

일하는 방식

기술보다 먼저, 사용자의 문제를 구체적으로 봅니다

요구사항을 작은 흐름으로 나누고, 동작하는 제품을 빠르게 만들며, 출시 후 실제 사용에서 발견한 문제를 다시 다룹니다. 접근성·개인정보·운영 가능성도 초기 설계에 포함합니다.

제가 기여하는 것

제품을 끝까지 책임지는 실행력

  • 모바일: Flutter 앱과 Firebase 연동, 인증·데이터 흐름
  • 웹: 제품형 웹앱, 다국어 사이트, 정적 배포와 SEO
  • 문제 해결: 막힌 이유와 검증 방법을 기록하고 재발을 줄이는 방식
  • 협업: 불확실한 요구를 작은 결정과 확인 가능한 결과로 전환

현재 개발 중 · Flutter · Firebase · AI

KINORA — 대화에서 시작하는 가족 돌봄

KINORA는 어르신이 AI 캐릭터와 자연스럽게 대화하며 식사, 수분 섭취, 복약, 수면, 통증, 기분 같은 일상을 돌아보고, 가족은 필요한 생활 변화와 안부를 확인하도록 돕는 서비스입니다. 감시를 늘리는 대신, 어르신의 자율성과 가족의 안심이 함께 지켜지는 경험을 만들고 있습니다.

01 · 어르신 앱

매일 쓰고 싶은 대화

캐릭터와의 대화를 통해 생활 상태를 부담 없이 표현하고, 이전 대화 맥락을 이어갈 수 있도록 설계합니다.

02 · 가족 경험

필요한 변화만 전달

가족에게 모든 대화를 공개하지 않고, 동의와 관계 범위 안에서 안부 확인에 필요한 요약을 전달하는 흐름을 고민합니다.

03 · 제품 엔지니어링

제품과 안전을 함께 설계

Flutter·Firebase 제품 구현과 함께 대화 기억, 데이터 최소화, 동의, 알림의 정확성과 실패 상황을 계속 검토합니다.
