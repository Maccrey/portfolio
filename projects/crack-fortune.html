FortuneCrack

3D 포춘 쿠키 깨기와 AI 점술가 상담을 결합한 인터랙티브 운세 플랫폼.

문제 정의

기존 운세 서비스의 정적인 텍스트 결과는 사용자에게 깊은 몰입감이나 개인화된 상담 경험을 제공하지 못함.

대상 사용자

매일의 운세를 재미있게 확인하고, 고민을 가볍게 상담하고 싶은 Gen Z 사용자

기여도

React Three Fiber로 3D 쿠키 인터랙션 구현, Gemini API 기반 페르소나 챗봇 설계, 게스트-로그인 데이터 동기화 개발.

임팩트

3D 애니메이션과 대화형 AI로 기존 텍스트 운세 대비 몰입도 높은 사용자 경험 제공.

기술 스택

ReactThree.jsFirebaseGemini API

하이라이트

  • 물리기반 3D 포춘 쿠키 깨기 인터랙션 (R3F)
  • Gemini Pro 기반의 '신비로운 점술가' 페르소나 챗봇
  • 게스트 모드에서 로그인 전환 시 데이터 자동 마이그레이션
